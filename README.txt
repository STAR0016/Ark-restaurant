Introduce functions:
Operating Details:
This system has numerous functions,
1. User registration and login, Manager login 

2. User Interface (Order Interface)
allows users to place orders and view the total price. In the "View Order" interface, users can modify the quantity of dishes and perform checkout operations.
After checkout, the system will save the order you placed (including the order ID, specific dishes ordered, total price, time, and payment method). 

3. Manager interface (Management interface),
i. You can view the existing dishes on the menu, and modify the quantity, name and inventory of the existing dishes.
You can delete an existing dish,
and also add a new dish (you need to select an image from your computer's folder as the photo). 

ii. On the order management page, you can view all the information of all the orders placed by everyone.
When you single-click on the order you want to view in detail, a pop-up window will appear to show which dishes are included in this order.
The manager can manually set the order to the "completed" status (all orders are set to the "pending" status by default when created). 

iii. Report Interface
There are three types of reports (Sales Report, Dish Analysis Report, Inventory Status Report)
The Sales Report generates a line chart based on the total amount of orders each day.
The Dish Analysis Report classifies dishes into different types based on the varying prices of each dish. There are three types in total. On the right side, a price range can be filled in to filter dishes.
The Inventory Status Report shows the current inventory of each dish in the restaurant, enabling timely adjustment of the purchasing strategy. 
All these three reports can be export as csv. file to the folder you want.


Regarding the "resources" folder:
It contains pictures of food that the restaurant needs to use, as well as a Sqlite driver.
